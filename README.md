🚀 DevTask Hub — TSIS6 (React + Firebase Auth + Кэширование)

Приложение представляет собой удобный менеджер задач для IT-команд. В этой версии (ТСИС6) я добавил полноценный вход через Firebase и умную систему кэширования данных.

🔗 Полезные ссылки

Сайт проекта (Vercel): https://devtask-hub-tsis6.vercel.app

Репозиторий (GitHub): https://github.com/Medeu06/devtask-hub-tsis6/tree/main


⭐️ Что умеет проект:

Авторизация и Регистрация (Firebase).

Вход по Email и паролю или в один клик через Google.

Настоящая регистрация новых пользователей с проверкой совпадения паролей.

Сессия не слетает при перезагрузке страницы.

Защищенные страницы (Protected Routes).

Страницы Профиль (/profile) и Дашборд (/dashboard) закрыты от гостей.

Если неавторизованный пользователь попытается зайти туда, его автоматически перенаправит на форму входа.

Работа с задачами:

Список задач с поиском, фильтрацией по категориям и статусам, сортировкой и пагинацией.

Просмотр подробностей задачи по ее уникальному URL (/tasks/TASK-1001).

Создание, редактирование, удаление и смена статусов.

⚡️ Как работает кэширование: 

Чтобы сайт работал быстрее и не нагружал систему повторными запросами, мы реализовали кэширование серверных данных в файле src/services/fakeApi.js.

1. Как сохраняются данные: 

Когда вы открываете список задач или карточку конкретной задачи, сайт загружает их и запоминает в памяти на 1 минуту (время VITE_CACHE_TTL_MS = 60000).

Если в течение этой минуты вы снова откроете эту же страницу, данные появятся мгновенно, без ожидания «загрузки из сети».

2. Когда кэш сбрасывается (Инвалидация):

Чтобы пользователь не видел устаревшую информацию, кэш автоматически очищается (clearCache()), как только происходят любые изменения.

Вы создали новую задачу ($\rightarrow$ кэш сбросился).

Вы отредактировали или удалили задачу ($\rightarrow$ кэш сбросился).

Вы изменили статус задачи (Reopen / Complete) ($\rightarrow$ кэш сбросился).

После этого следующий запрос загружает уже абсолютно свежие данные.
